# 🎭 Emotion Classification Dataset for NLP

A clean and structured dataset for **Emotion Detection** in text, curated for NLP classification tasks. Perfect for training machine learning models to identify human emotions in written content.

---

## 📚 About the Dataset

This dataset contains:
- A collection of text documents
- Each labeled with one of several emotions (e.g., `joy`, `sadness`, `anger`, etc.)
- Pre-split into `train`, `test`, and `validation` sets for model development
